Eaglercraft (hotlinked screenshots)

This file collects a few representative screenshots of Eaglercraft (the browser-based Minecraft project) by hotlinking images hosted on the official site. Use these as visual references for the README or a demo page. If you want local copies, see the note at the bottom.

Attribution & licensing: images are hosted on eaglercraft.com; review their site for usage terms. If you prefer local files, download the images and place them under assets/, then update the <img> src attributes to point to the local paths.

Quick commands to download locally (run in repo root):

mkdir -p assets && \
curl -L -o assets/ss1.png https://eaglercraft.com/images/screenshots/ss1.png && \
curl -L -o assets/ss2.png https://eaglercraft.com/images/screenshots/ss2.png && \
curl -L -o assets/ss3.png https://eaglercraft.com/images/screenshots/ss3.png
