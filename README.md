# Eaglecraft

![Eaglecraft](assets/banner.png)

Eaglecraft is a lightweight static HTML project and demo site built to showcase creative layouts, components, and micro-interactions — a tiny playground for front-end ideas.

> A playful, minimal project for crafting beautiful HTML experiences.

## Features

- Single-page static HTML site (no build tools required)
- Responsive layout and accessible markup
- Example components: hero, gallery, cards, and a contact snippet
- Ready for customization and deployment to GitHub Pages

## Demo

Open `index.html` in a browser to see the demo. If the repo contains an `assets/` folder, images referenced there will appear automatically.

## Installation

1. Clone the repo:

```bash
git clone https://github.com/camdenbecker11-sudo/Eaglecraft.git
cd Eaglecraft
```

2. Open `index.html` in your browser:

```bash
open index.html # macOS
# or just double-click index.html in your file explorer
```

## Usage

- Edit the HTML files to add sections or components.
- Add styles in `styles/` or inline in the HTML if present.
- Drop images into `assets/` and reference them from the markup.

## Development

This project is intentionally simple: no Node.js, no bundlers, just HTML/CSS (and optionally JS).

To iterate quickly, use a live-reload extension or VS Code Live Server.
